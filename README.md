Программа оптимизирующая модель работы агрохолдинга в период уборки урожая.

#Justfile

Команды justfile описывают работу проекта. Для запуска команды необходимо прописать в консоли just имя_команды.

Имена и действия команд описаны ниже:

generate GENERATION_PARAMS_FILE_NAME - генерация json фалйла с входными константами модели.

server - запуск сервера cuOpt

gpu - запуск создания модели по файлу с входными данными модели, сохранение модели в общем формате и формате mps. Создание модели и отправка модели на решение в cuOpt.

highs - запуск решения модели, сохраненной после запуска gpu. Сохранение решения в формате sol.

fetch REQ - выгрузка решенной сервером cuOpt модели по REQ ID и сохранение решения в формате json.

analyze FOLDER - анализ полученного решения после загрузки через fetch решения от cuOpt.

ansol FOLDER - анализ полученного решения после сохранения через highs.

kill - остановка работы сервера.
